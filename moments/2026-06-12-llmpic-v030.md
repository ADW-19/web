# LLMPIC Python SDK v0.3.0 Released

LLMPIC (LLM Plot In Chart) is an open-source project incubated from my work on enterprise data platforms, designed to solve the problem of traditional BI charting being unable to invoke AI agents. Today v0.3.0 is officially released on PyPI.

## What's New

This release fixes memory issues and significantly improves invocation speed and runtime stability — one sentence is all it takes to generate a publication-ready chart.

![LLMPIC demo](project/llmpic.png)
*LLMPIC: charts from a single sentence*

## Links

- [GitHub: github.com/ADW-19/llmpic](https://github.com/ADW-19/llmpic)
- [PyPI: pypi.org/project/llmpic](https://pypi.org/project/llmpic/)
- [Documentation](https://github.com/ADW-19/llmpic/tree/main/doc)

Install or upgrade with a single command:

```
pip install llmpic --upgrade
```
